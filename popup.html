WhatSave

Bulk WhatsApp exporter with chat-order media, captions, replies, and viewing links

Select one or more chats. Export numbers start at 0001 and follow the chat from oldest to newest across the selected media and links. Caption matching never searches distant messages.

Statistics reflect messages currently loaded in WhatsApp Web. Links are text messages containing a web address or WhatsApp link-preview URL. Load more messages before exporting older items.

Media type

Links are taken from the same messages loaded for the selected chat, then filtered by the selected date range. This keeps link exports scoped to the chosen chat/group. A link is exported only when a real URL is found in the selected chat. WhatSave checks message/link-preview fields first and the visible message HTML as a fallback, so clickable viewing links that WhatsApp does not expose in the message object can still be captured.

Date range

Leave both fields empty to include all dates. The filter applies to each item’s message timestamp, including links.

Options

Sorts the complete scanned chat timeline before captions, links, numbering, and saving. Item numbers are assigned in chat order, and individual downloads are saved in that same order.

The selected pattern uses each message timestamp. Date format changes only the filename; it never changes chat order. The sequence number stays first (0001_, 0002_, …) so Windows Explorer sorts the exported files naturally.

Example: 0001_Chat_2026-09-23_15-30-45.jpg

Only the single message immediately after the media in the verified chronological chat sequence is considered. It must be plain text, from the same chat and sender, and within 15 seconds. No later message is searched. If adjacency cannot be proven, the media stays without a recovered caption.

Only a plain-text reply with an exact WhatsApp reference to this specific media is accepted. Approximate or partial IDs are rejected. A reply that points somewhere else is never used as the caption.

Links are detected from the selected chat’s normal message history and exported as one UTF-8 .txt per link message. The first real URL is included in the filename, and every URL found in that message is written inside the .txt. Messages outside the selected chat or date range are ignored.

Higher values speed up fetching. With Preserve chat order enabled, media can be fetched in parallel, but the final files are saved oldest → newest. Links are exported as UTF-8 .txt files in the same sequence.

Captions and links: the media’s own caption has priority. A direct reply is used only when WhatsApp explicitly points to that exact media. A next-message caption is used only for the literal immediately following text message in verified chat order. Unrelated or uncertain text is never attached. Items selected as Links are exported as UTF-8 .txt files. WhatSave scans the selected chat’s dedicated URL-message results and also reads link-preview URL fields. The full URL is written inside the file and a safe version of the first URL appears in the filename.
